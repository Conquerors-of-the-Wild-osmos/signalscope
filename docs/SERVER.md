# Сервер Signalscope

[Вернуться к руководству игрока](../README.md)

## Установка вручную

1. Подготовьте Fabric-сервер Minecraft 1.21.1 с Java 21 или новее
   и Fabric Loader 0.20.1 или новее.
2. Поместите в `mods/` один JAR Signalscope из
   [релиза](https://github.com/Conquerors-of-the-Wild-osmos/signalscope/releases/latest),
   Fabric API, Simple Voice Chat и YACL. Нужны версии для Fabric и Minecraft 1.21.1.
   Требования к зависимостям перечислены в [README](../README.md#установка).
3. Запустите сервер. Игрокам нужен тот же набор обязательных модов.
   Mod Menu нужен только клиентам, которые хотят менять настройки через интерфейс.
4. Откройте игровой порт TCP и отдельный UDP-порт Simple Voice Chat.
   По умолчанию это **25565/TCP** и **24454/UDP**.
5. Проверьте подключение SVC на двух клиентах и выполните
   [первый разговор](../README.md#первая-игра-вдвоём).

Если Minecraft работает, а SVC не подключается, проверьте именно UDP-порт:
доступный игровой TCP-порт не означает, что голосовой порт открыт.
Настройки SVC находятся в `config/voicechat/voicechat-server.properties`.

Для обновления остановите сервер, замените старый JAR Signalscope новым и запустите
сервер снова. Обновите мод у игроков; не оставляйте несколько его версий в `mods/`.

## Docker Compose

В корне репозитория находится [compose.yaml](../compose.yaml).
Он использует образ `itzg/minecraft-server:java21`, устанавливает Fabric-сервер
Minecraft 1.21.1, зависимости и Signalscope из последнего GitHub Release.
Нужны Docker с Compose и доступ к интернету.

```sh
git clone https://github.com/Conquerors-of-the-Wild-osmos/signalscope.git
cd signalscope
docker compose up -d
```

Просмотр логов и остановка:

```sh
docker compose logs -f mc
docker compose down
```

Мир, конфигурация и установленные серверные моды сохраняются в `data/`.
Остановка контейнера не удаляет этот каталог.

Конфигурация передаёт `EULA=TRUE` по умолчанию: запуск предполагает согласие
с Minecraft EULA. Значения можно задать в окружении или файле `.env` рядом
с `compose.yaml`:

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `MEMORY` | `8G` | Память JVM сервера |
| `MC_PORT` | `25565` | Внешний TCP-порт Minecraft |
| `VOICE_PORT` | `24454` | Внешний UDP-порт голосового чата |
| `SIGNALSCOPE_MODS` | URL последнего релиза | Источник JAR вместо стандартной загрузки |

При изменении внешнего голосового порта также настройте адрес/порт, который
SVC сообщает клиентам, через `voice_host` в
`data/config/voicechat/voicechat-server.properties`.
Одной переадресации порта контейнера может быть недостаточно.

Дополнительные совместимые Fabric-моды можно положить в `mods/` рядом
с `compose.yaml`. После изменения набора модов перезапустите сервис:

```sh
docker compose restart mc
```

После изменения переменных окружения примените конфигурацию повторным
`docker compose up -d`. Игроки устанавливают клиентские моды самостоятельно.

## Особенности мира

- Радиосвязь и обнаружение работают в пределах одного измерения.
- Обычный чат по близости и группы SVC заменены передачей через рацию.
- Приёмники работают, пока игра обрабатывает их область мира.
- Активные передатчики сохраняют последнее известное состояние при выгрузке
  чанка. Активные области блокировщиков также сохраняются.
- Мод специально не загружает чанки ради работы этих блоков.
